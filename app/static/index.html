Topologie naar binnen naar buiten

Laden…

De stroom naar en van een node is het gemiddelde van de laatste minuut (uit Proxmox); die van een container of VM wordt elke 2 seconden bijgewerkt. Hoe dikker en sneller de stroom, hoe meer verkeer. Het verkeer naar een opslag is een schatting uit de schijven van de guests; bij Ceph staat het verkeer van het hele cluster in het vak. Klik op een guest om hem in het overzicht te tonen.

VLAN voor containers en VM's

  

    

    
    
    

  

  
Het VLAN komt op alle nodes, als netwerk dat je daarna kiest bij een container of VM. De naam: 2 tot 8 kleine letters of cijfers, beginnend met een letter.

  
Je switch en router moeten dit VLAN-nummer wel doorlaten naar de nodes; dat regel je daar, niet hier.

  
 




  
VLAN-interface op een node

  

    

    

    

    
    
  

  
De node krijgt een eigen aansluiting in dit VLAN, bijvoorbeeld om een opslagnetwerk te bereiken. Er komt geen gateway bij: de node houdt zijn bestaande route naar buiten.

  
Voor containers en VM's heb je dit niet nodig; kies daarvoor "VLAN voor containers en VM's".

      Console van een node
      
  
      Proxmox geeft een shell op een node alleen aan een account van de node zelf (realm pam), zoals root. Log daarmee in. De tool bewaart je wachtwoord niet en onthoudt het inloggen alleen voor deze sessie, hooguit een uur.
      
  
      Staat root in Proxmox uit, gebruik dan een ander pam-account dat een console mag openen (het recht Sys.Console op de nodes). De console vraagt dan zelf nog een keer om in te loggen.
      
  
      
    
       @pam
      
    
    
       uit je authenticator-app, of een herstelcode
      
  
      
  
      
  
       
      
      


  
      Beveiligingssleutels
      
  
      Met een beveiligingssleutel, zoals een YubiKey, of een passkey log je in zonder wachtwoord. Je kunt hem ook na je wachtwoord als extra stap laten vragen.
      
  
      Beveiligingssleutels werken alleen als je de tool via een naam opent (bijvoorbeeld je Cloudflare-adres), niet via een IP-adres. Open de tool via zo'n naam om een sleutel toe te voegen.
